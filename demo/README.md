# Demo Scripts

This directory contains demonstration scripts that showcase various capabilities of JARVIS-MK42.

## Available Demos

### AI Capabilities
- **demo_ai_capabilities.py** - Demonstrates Phase 2B.4 advanced AI integration capabilities including cognitive models, multi-modal processing, adaptive learning, and knowledge management.

### Research Capabilities  
- **demo_enhanced_research_agent.py** - Shows enhanced research agent functionality with comprehensive information gathering and analysis.

### Document Intelligence
- **demo_enhanced_document_intelligence.py** - Demonstrates document intelligence capabilities including analysis, comparison, and extraction.

### Multi-Agent Orchestration
- **demo_phase_2b2.py** - Shows Phase 2B.2 multi-agent orchestration capabilities.
- **demo_phase_2b2_integration.py** - Demonstrates integration aspects of multi-agent orchestration.

### Language Detection
- **demo_phase_2b3_language_detection.py** - Shows Phase 2B.3 language detection and processing capabilities.

## Running the Demos

To run any demo script:

```bash
cd demo
python demo_<name>.py
```

Make sure you have:
1. All required dependencies installed (see ../requirements.txt)
2. Environment variables configured (see ../.env.example)
3. JARVIS-MK42 application running (if the demo requires it)

## Note

These demo scripts are for development and testing purposes. They showcase specific features and capabilities but are not part of the production application.
